# SMS / Email Spam Classifier

A machine learning based web application to classify SMS or email messages as spam or ham.

## Tech Stack
- Python
- Flask
- Scikit-learn
- TF-IDF
- HTML, CSS

## Features
- Text preprocessing using NLP
- Naive Bayes classification
- Ready for deployment

## Run Locally
```bash
pip install -r requirements.txt
python app.py
